# Fitness Trainers Platform — progress

## Project vision

Build a SaaS platform for fitness coaches.

### Coaches can

- Manage trainees
- Create workout plans
- Create nutrition plans
- Upload content/posts
- Track trainee progress
- View progress photos

### Trainees can

- View workout plans
- View nutrition plans
- Upload progress photos
- View coach content

## Implementation status

- **Stack:** Next.js (App Router) — default scaffold; home is still the starter page (`src/app/page.tsx`).
- **Next steps:** Define auth, roles (coach vs trainee), data model, and core flows; then replace the starter UI with product routes.
